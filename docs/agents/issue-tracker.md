# Issue tracker: Local Markdown

Specs and tickets live under `.scratch/<feature-slug>/`.

- Spec: `spec.md`.
- Tickets: `issues/<NN>-<slug>.md`, numbered from `01`, one file per ticket.
- Record workflow state as a `Status:` line near the top. A spec approved for implementation uses `Status: ready-for-agent`.
- Append discussion under `## Comments`.

“Publish to the issue tracker” means create the corresponding local file.
“Fetch the relevant ticket” means read the referenced file.
