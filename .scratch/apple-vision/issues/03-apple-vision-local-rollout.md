# 03: Установленный OCR-инструмент и инструкции готовы к использованию

Status: done

**What to build:** Пользователь может применять новый движок через установленный локальный OCR CLI, а исходный и установленный OCR-скилл объясняют выбор Apple Vision, его требования и ограничения на основе проверенных результатов.

**Blocked by:** 02 — Apple Vision в PDF-пайплайне и строгой эскалации.

## Acceptance criteria

- [x] Перед изменением окружения подтверждены установка необходимых зависимостей и обновление локального CLI; при отсутствии подтверждения этап остановлен до решения пользователя.
- [x] PyObjC установлен в изолированное окружение OCR, а локальный CLI обновлён из проверенных исходников без изменения системного Python.
- [x] Установленный CLI успешно распознаёт локальные фотографии текущей сессии и многостраничный PDF через `apple-vision`.
- [x] Проверены содержимое существенных строк, уверенность и корректность координат; успешность не определяется одним количеством символов.
- [x] Зафиксированы условия и длительность прогонов и проверенная совместимость Python/macOS. Причины задержек и поддержка непроверенных платформ не выданы за установленные факты.

- [x] Инструкции объясняют явный выбор `apple-vision`, optional extra, режим `.accurate`, ошибки требований и участие в эскалации; отличают локальный `apple-vision` от API-движка `vision`.
