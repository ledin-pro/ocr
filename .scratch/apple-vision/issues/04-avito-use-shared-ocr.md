# 04: Avito использует общий OCR вместо собственной реализации

Status: done

**What to build:** Агент при подготовке объявлений использует общий OCR-скилл и доступные инструменты, а не отдельную OCR-реализацию внутри Avito. Замена выполняется после подтверждённой работоспособности установленного общего движка.

**Blocked by:** 03 — Установленный OCR-инструмент и инструкции готовы к использованию.

## Acceptance criteria

- [x] Собственная Python-проверка ориентации и Swift OCR-хелпер удалены из Avito после успешной проверки общей реализации.
- [x] Инструкции и карта ссылок направляют агента к OCR-скиллу и доступным инструментам вместо запуска или повторного создания удалённой реализации.
- [x] Regression eval обновлён под новый рабочий процесс и проверяет обращение к общему OCR вместо удалённого скрипта.
- [x] Сохранены генерация превью поворотов, нормализация фотографий, линтер объявления и браузерная обёртка.
- [x] Сохранено предупреждение о ненадёжности выбора поворота по количеству распознанных символов, без универсального утверждения, что никакой OCR не различает 0° и 180°.
- [x] В актуальных инструкциях, карте ссылок и eval нет ссылок на удалённый код как на доступный инструмент.
- [x] Кэш и другие файлы вне затронутых репозиториев не удалены; несвязанные пользовательские изменения сохранены.
- [x] Коммиты, push и релиз не выполнены без отдельного запроса пользователя.
